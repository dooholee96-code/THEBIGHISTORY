이 폴더(`data/`)의 연표 데이터는 **CC BY 4.0**(저작자 표시 4.0 국제) 으로 제공합니다.

- 저작권: Copyright (c) 2026 dooholee96-code
- 상업적 이용, 수정, 재배포 모두 허용되며 **저작자 표시**만 지키면 됩니다.

## 왜 CC BY 인가

- 코드(MIT)와 달리 데이터는 별도로 표기하는 편이 분쟁 소지가 적습니다.
- **CC BY-SA(동일조건변경허락)를 피했습니다.** SA 계열은 2차적 저작물도 같은 조건으로
  공개해야 해서, 이 데이터를 쓴 서비스 전체에 의무가 번질 수 있습니다.

## 데이터를 채울 때 지켜야 할 것 (중요)

상업적 이용에 문제가 생기는 거의 유일한 경로가 **다른 저작물의 문장을 그대로 옮기는 것**입니다.
항목을 추가·수정할 때 아래를 지켜 주세요.

1. **연도·사건명 같은 사실은 자유롭게 가져와도 됩니다.** 사실 자체는 저작권 보호 대상이 아닙니다.
2. **설명문(`description`, `summary`)은 반드시 직접 쓰세요.**
   위키백과·나무위키·백과사전·논문의 문장을 복사하거나 몇 단어만 바꿔 옮기면 안 됩니다.
   - 위키백과는 **CC BY-SA** 입니다. 문장을 옮기면 이 데이터 전체가 CC BY-SA 의무에
     묶일 수 있어, 광고를 붙인 서비스에서 특히 곤란해집니다.
   - 나무위키는 별도 이용약관이 있어 더 제한적입니다.
3. **자료는 `sources` 에 확인용으로 적으세요.** 링크를 적는 것은 문제가 없습니다.
   문장을 옮기지 않고 "확인에 사용한 자료"로만 쓰면 됩니다.
4. 이미지·지도·도표는 이 저장소에 넣지 마세요. 넣어야 한다면 라이선스를 개별 확인하고
   `THIRD-PARTY-NOTICES.md` 에 고지를 추가하세요.

`npm run validate` 가 `sources` 에 위키 계열 링크가 있으면 2번 규칙을 다시 알려 줍니다.
